# autosync_repos.txt — source of truth for which repos git_autosync pushes.
# One repo per line. A bare name resolves under ~/Documents/lab/active/.
# You can also give an absolute path (/Users/...) or a ~/path.
# Lines starting with # and blank lines are ignored.
#
# Only repos that already have a GitHub 'origin' remote are synced;
# others are skipped with a notice.
#
# MODES. A repo may carry a flag after its name:
#
#     imprint  push-only
#
# push-only  Push commits that already exist; never stage or commit the working
#            tree, and never publish a branch that has no upstream. Use it for
#            any repo a person or an agent is actively working in. The default
#            (a sweep: git add -A, commit, push) is right for a repo nobody
#            edits between runs, and wrong for one that is mid-change — it rolls
#            unrelated half-finished work into one "autosync: <timestamp>"
#            commit that looks like history and is painful to unpick.
#
# The gitleaks history scan runs in both modes. The staged scan is skipped in
# push-only because nothing is staged.

# alone.
